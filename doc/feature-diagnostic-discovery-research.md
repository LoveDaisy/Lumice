# 通用特征发现：研究判据

> 状态：研究结论，不是已实现的发现 API（2026-10-04）。现有 path-feature report 仍是固定案例检测器；本文不改变其支持范围、schema 或 analytic 库版本。

相关：[分析路线图](raypath-analysis.md)、[analytic 能力](analytic-api.md)、[光路对称语义](raypath-symmetry.md)、[数值鲁棒性](numerical-robustness.md)。

## 1. 要解释的对象

机制候选与可见特征是两个对象。对一个具体成员和波长，令 `F(q)` 为出射方向，`A(q)` 为有限晶体的有效入射面积，`T(q)` 为各接口能量因子的乘积，`mu` 为明确指定的输入分布。天空测度是推送 `F_*(A T mu)`。`F` 的临界集是解释该测度的证据，不是实际测度的替代品。跨随机形状的产品归一化必须服从产品物理测度；孤立 analytic 查询的绝对面积约定不能静默充当场景的相对丰度约定。

三类实测反例约束发现算法：

- 平滑姿态密度极大能在受限映射导数非零的位置产生天空极大。只找临界集会漏掉它。
- 光学临界点可以仍然方向有效，但有限晶体的入射面积为零。候选存在不等于它产生亮特征。
- 采样、平滑后的颜色分数极大可能随采样实现移动。在某张图上找到期待的特征，不构成峰检测器可靠的证据。

因此要求是**双向核对**：寻找实际天空结构及其机制证据，同时用实际支持、权重和天空结构检验机制候选。这不规定谁必须先跑，更不要求在证明搜索可行之前冻结 callback、胞元或场 ABI。

## 2. 条件机制与混合分布

条件映射固定一部分输入，联合天空测度对它们积分。两者都需要。有限太阳盘或姿态展宽可以拓宽严格取向族的特征，而不推翻条件族上的机制；反过来，条件临界值也不必等于展宽、像素积分后的实际峰值。

例如：规则棱柱、`3-5`、折射率 1.31、太阳高度 20°、严格水平 `Rz` 族的条件极小偏向方位角为 24.576446583°。独立核对是在该实际侧面几何下，把水平有效折射率 `sqrt(n*n - sin(h)*sin(h))/cos(h)` 代入棱镜最小偏折关系。0.25°天空网格、0.3°平滑得到的加权峰却位于 24.875°。两者回答的是不同问题，不是同一观测量的竞争估计。

在同一条件极小点，把柱高/直径比从 1 降到 0.1，方向映射仍有效，但引擎长度单位下的 `A` 从约 0.277072 降为零；独立有限走廊算法也给出零。此处是点级支持证据，不能把其他位置的有限采样空表升级为整条光路物理不可达的证明。

因此诊断记录需要同时说明：机制在哪些条件下求值、与实际分布有什么关系、实际特征的位置/范围及数值尺度。不得把有限宽集中报成严格降维，也不得把单点 rank-0 报成正质量原子。当实际面法向和光学序列满足条件时，平行板恒等式是合法的整域原子论证；单点小 Jacobian 不是。

## 3. 局部光谱证据

某个天空点的颜色分数不是空间色边。必须在同一空间域上比较光谱支持、位置、权重及局部变化。无光网格没有颜色分数；给它填中性值，会人为造出该观测量的边界。

有用的因果探针只改变一个接口的标量权重，保持几何、样本、入射面积及其他权重不动。两指数 `3-1-5` 探针（1.307、1.317）中，短谱占比的原始峰在独立 scramble 间从 134.3° 移到 138.9°；同位置配对的内部反射效应峰仍为 137.7°，在声明的尺度与对比规则下，作用范围约 130.3–139.9°。这支持机制配对，不是通用检测阈值，更不是整幅混合场景下“肉眼可见”的证明。产品仍须使用实际谱权重和相关波长。

移除因子是诊断性干预，不是另一种物理仿真。内部 TIR discriminant 是反射权重的 kink，不是自动的有效域门。每个内部接口都要有自己的身份；只处理首个接口不能解释一般光路。

## 4. 数值与消费者边界

- 特征必须带局部分辨率、平滑尺度和误差。总能量收敛既不能证明局部定位，也不能成为丢弃已验证局部候选的理由。
- 区分候选、已证机制、实际图上结构、搜索未解与物理不可达。增加采样预算不是全域完备性证明。
- 数值检查须看条件数。出口 Snell discriminant 约 `2.6e-15` 时，约 `2e-16` 的差异会把其平方根改变约 `1.9e-9`。内域有效的统一绝对方向容差在这里可能失败，却不代表光学分支发生变化。保留失败测量，找首个分叉原语，不静默放宽全局容差。
- 独立 analytic 库是 LI 数值消费者的计算边界；Scene 解析、物理成员选择和报告序列化留在引擎。接口接收具体光路，不提供对称约化。
- 当前 `EvaluatePath` 可用于计算偏折角、复制逐接口权重，但不是原生批量场、Hessian、逐姿态入射面积或通用特征发现 API。消费者有限差分能验证用途，却不能成为让 LI 永久重写成熟共享算法的理由。
- 独立 JAX/解析 expected 与共用 C++ 的集成一致性测试各有用途，不可混同。几何、光学、对称原语在两仓继续独立实现。

## 5. 尚未解决的研究，不是隐含的实现细节

上述实验没有建立通用机制引导发现算法。开放/多分量曲线、角点、退化集、局部搜索预算、稳定平滑脊线、全部取向族、相关随机形状、完整光谱和多层复合仍需可运行证据。它们是宣布通用报告或共享发现 ABI 就绪之前的研究依赖，不是给旧固定案例白名单扩容的要求。

这些结论支持复用现有路径与有限走廊原语，排除了几条不充分的路线；它们不声称所有产品输入都已覆盖。

## 6. 形态匹配的局部尺子

宽色带不必有唯一稳定的峰点。对同一组独立采样结果，短谱占比的最高点相差
4.6°，但在明确声明的 0.55 / 0.60 / 0.65 水平下，带左端的重复差只有
0.23–0.43°。这支持以带域而非单个 argmax 描述该结构，**不**把这三个数变成通用
可见性阈值。右端则被计算时的亮度掩码截断；掩码边不是物理边，输出须说明删失原因。

另一类量不能由此替代：条件曲线的零方程残差与有限支持端点的定位误差彼此独立。
一条非对称锥晶的第二内部反射 kink 曲线，零方程残差已经小于 `1e-11`，但以
0.5° 步长采下的有限支持端点仍漏掉 0.36–0.75° 的天空范围。沿曲线对 `A=0` 与
`A>0` 的相邻点二分后，换为 0.25° 步长及更密的种子网格，端点差降到
`4.42e-7°` 以下；独立有限晶体计算确认了端点两侧的支持转换。这里得到的是
**已找到分量的局部定位精度**，不是没有遗漏其他分量的证明。

## 7. 数值路线的新增证据与边界

对一维取向支持，可以把有效曲线分成单调段，在每个逆像上求和
`A T rho / |d(azimuth)/dq|`，然后寻找实际线密度的极值。规则棱柱 `3-5`、太阳高度
20°、折射率 1.31、取向坐标标准差 0.02 rad 的两组高斯分布，均值分别为 1.0 / 1.1 rad，
给出连续密度峰 26.515491° / 28.290156°。它们不是映射的临界值，也不严格等于
取向均值映射后的角度。一次本地研究测量中，包含种子、分段、求逆和优化的时间为
0.053–0.070 s，采样与图像聚合为 0.077–0.096 s。这个比较说明连续求解在一维中
未必更贵，不是其他输入的预算承诺；其密度单位是每 rad 方位角，不是每 sr。

逐接口验证必须保留负例。在一条四面序列棱柱光路中，第二内部接口全反射，移除该
因子的配对效应为零；换为非参考、不对称上下锥及非均匀面距的四面序列后，第二内部
接口可在宽空间域贡献约 0.07 的短谱占比变化。实际最强色边却不位于该接口 kink
曲线的投影范围内。因此需要保留实际结构、条件曲线、有限支持和因子介入的不同
空间范围，不能把 `discriminant=0` 的像直接当成混合后色带的轮廓。

原生数值消费也有了研究证据，但尚未成为新公开 API：以现有 `TracePathChain`
模板配合独立验证过的二阶对偶数算子，能输出显式球面切基中的梯度与 Hessian，
经过研究 C 批量桥，由 Python 消费者执行临界点 Newton 求解。两种晶体的实际
捕获点对独立 JAX Hessian 的最大绝对误差约 `1.6e-11`，Newton 结果对独立解析
方向的残差约 `1.3e-13`。折射率和门函数导数在该研究桥中仍是原生双尺度有限差分，
不是 AD；不可用项没有由调用方差分填补。

这一原型还揭示了可用性边界：若门函数的差分也要求整条光路在扰动后有效，即使所求
的是较早内部接口的量，出口临界点附近也会因为末端门失败而拒绝它。已追踪的曲线
因此在出口 Snell discriminant 仍约为 `2.5e-5` 时被数值截断，而非真正走到物理端点。
“整体路径有效”和“某个局部字段可求值”不能在后续接口中默认为同一个谓词。

以上模块尚未组成一般各向异性天空的共同发现器。二维亮线／带域的连续积分与搜索、
条件机制和实际结构的自动关联、稀支持／多分量／高阶退化的局部未完成信号，仍然是
产品化前的研究依赖。它们没有因原生批量数值或一条开弧已经可用而自动解决。
