# 通用特征发现：研究判据

> 状态：研究结论，不是已实现的发现 API（2026-10-04）。现有 path-feature report 仍是固定案例检测器；本文不改变其支持范围、schema 或 analytic 库版本。

相关：[分析路线图](raypath-analysis.md)、[analytic 能力](analytic-api.md)、[光路对称语义](raypath-symmetry.md)、[数值鲁棒性](numerical-robustness.md)。

## 1. 要解释的对象

机制候选与可见特征是两个对象。对一个具体成员和波长，令 `F(q)` 为出射方向，`A(q)` 为有限晶体的有效入射面积，`T(q)` 为各接口能量因子的乘积，`mu` 为明确指定的输入分布。天空测度是推送 `F_*(A T mu)`。`F` 的临界集是解释该测度的证据，不是实际测度的替代品。跨随机形状的产品归一化必须服从产品物理测度；孤立 analytic 查询的绝对面积约定不能静默充当场景的相对丰度约定。

三类实测反例约束发现算法：

- 平滑姿态密度极大能在受限映射导数非零的位置产生天空极大。只找临界集会漏掉它。
- 光学临界点可以仍然方向有效，但有限晶体的入射面积为零。候选存在不等于它产生亮特征。
- 采样、平滑后的颜色分数极大可能随采样实现移动。在某张图上找到期待的特征，不构成峰检测器可靠的证据。

因此要求是**双向核对**：寻找实际天空结构及其机制证据，同时用实际支持、权重和天空结构检验机制候选。这不规定谁必须先跑，更不要求在证明搜索可行之前冻结 callback、胞元或场 ABI。

## 2. 条件机制与混合分布

条件映射固定一部分输入，联合天空测度对它们积分。两者都需要。有限太阳盘或姿态展宽可以拓宽严格取向族的特征，而不推翻条件族上的机制；反过来，条件临界值也不必等于展宽、像素积分后的实际峰值。

例如：规则棱柱、`3-5`、折射率 1.31、太阳高度 20°、严格水平 `Rz` 族的条件极小偏向方位角为 24.576446583°。独立核对是在该实际侧面几何下，把水平有效折射率 `sqrt(n*n - sin(h)*sin(h))/cos(h)` 代入棱镜最小偏折关系。0.25°天空网格、0.3°平滑得到的加权峰却位于 24.875°。两者回答的是不同问题，不是同一观测量的竞争估计。

在同一条件极小点，把柱高/直径比从 1 降到 0.1，方向映射仍有效，但引擎长度单位下的 `A` 从约 0.277072 降为零；独立有限走廊算法也给出零。此处是点级支持证据，不能把其他位置的有限采样空表升级为整条光路物理不可达的证明。

因此诊断记录需要同时说明：机制在哪些条件下求值、与实际分布有什么关系、实际特征的位置/范围及数值尺度。不得把有限宽集中报成严格降维，也不得把单点 rank-0 报成正质量原子。当实际面法向和光学序列满足条件时，平行板恒等式是合法的整域原子论证；单点小 Jacobian 不是。

## 3. 局部光谱证据

某个天空点的颜色分数不是空间色边。必须在同一空间域上比较光谱支持、位置、权重及局部变化。无光网格没有颜色分数；给它填中性值，会人为造出该观测量的边界。

有用的因果探针只改变一个接口的标量权重，保持几何、样本、入射面积及其他权重不动。两指数 `3-1-5` 探针（1.307、1.317）中，短谱占比的原始峰在独立 scramble 间从 134.3° 移到 138.9°；同位置配对的内部反射效应峰仍为 137.7°，在声明的尺度与对比规则下，作用范围约 130.3–139.9°。这支持机制配对，不是通用检测阈值，更不是整幅混合场景下“肉眼可见”的证明。产品仍须使用实际谱权重和相关波长。

移除因子是诊断性干预，不是另一种物理仿真。内部 TIR discriminant 是反射权重的 kink，不是自动的有效域门。每个内部接口都要有自己的身份；只处理首个接口不能解释一般光路。

## 4. 数值与消费者边界

- 特征必须带局部分辨率、平滑尺度和误差。总能量收敛既不能证明局部定位，也不能成为丢弃已验证局部候选的理由。
- 区分候选、已证机制、实际图上结构、搜索未解与物理不可达。增加采样预算不是全域完备性证明。
- 数值检查须看条件数。出口 Snell discriminant 约 `2.6e-15` 时，约 `2e-16` 的差异会把其平方根改变约 `1.9e-9`。内域有效的统一绝对方向容差在这里可能失败，却不代表光学分支发生变化。保留失败测量，找首个分叉原语，不静默放宽全局容差。
- 独立 analytic 库是 LI 数值消费者的计算边界；Scene 解析、物理成员选择和报告序列化留在引擎。接口接收具体光路，不提供对称约化。
- 当前 `EvaluatePath` 可用于计算偏折角、复制逐接口权重，但不是原生批量场、Hessian、逐姿态入射面积或通用特征发现 API。消费者有限差分能验证用途，却不能成为让 LI 永久重写成熟共享算法的理由。
- 独立 JAX/解析 expected 与共用 C++ 的集成一致性测试各有用途，不可混同。几何、光学、对称原语在两仓继续独立实现。

## 5. 尚未解决的研究，不是隐含的实现细节

上述实验没有建立通用机制引导发现算法。开放/多分量曲线、角点、退化集、局部搜索预算、稳定平滑脊线、全部取向族、相关随机形状、完整光谱和多层复合仍需可运行证据。它们是宣布通用报告或共享发现 ABI 就绪之前的研究依赖，不是给旧固定案例白名单扩容的要求。

这些结论支持复用现有路径与有限走廊原语，排除了几条不充分的路线；它们不声称所有产品输入都已覆盖。

## 6. 形态匹配的局部尺子

宽色带不必有唯一稳定的峰点。对同一组独立采样结果，短谱占比的最高点相差
4.6°，但在明确声明的 0.55 / 0.60 / 0.65 水平下，带左端的重复差只有
0.23–0.43°。这支持以带域而非单个 argmax 描述该结构，**不**把这三个数变成通用
可见性阈值。右端则被计算时的亮度掩码截断；掩码边不是物理边，输出须说明删失原因。

另一类量不能由此替代：条件曲线的零方程残差与有限支持端点的定位误差彼此独立。
一条非对称锥晶的第二内部反射 kink 曲线，零方程残差已经小于 `1e-11`，但以
0.5° 步长采下的有限支持端点仍漏掉 0.36–0.75° 的天空范围。沿曲线对 `A=0` 与
`A>0` 的相邻点二分后，换为 0.25° 步长及更密的种子网格，端点差降到
`4.42e-7°` 以下；独立有限晶体计算确认了端点两侧的支持转换。这里得到的是
**已找到分量的局部定位精度**，不是没有遗漏其他分量的证明。

## 7. 数值路线的新增证据与边界

对一维取向支持，可以把有效曲线分成单调段，在每个逆像上求和
`A T rho / |d(azimuth)/dq|`，然后寻找实际线密度的极值。规则棱柱 `3-5`、太阳高度
20°、折射率 1.31、取向坐标标准差 0.02 rad 的两组高斯分布，均值分别为 1.0 / 1.1 rad，
给出连续密度峰 26.515491° / 28.290156°。它们不是映射的临界值，也不严格等于
取向均值映射后的角度。一次本地研究测量中，包含种子、分段、求逆和优化的时间为
0.053–0.070 s，采样与图像聚合为 0.077–0.096 s。这个比较说明连续求解在一维中
未必更贵，不是其他输入的预算承诺；其密度单位是每 rad 方位角，不是每 sr。

逐接口验证必须保留负例。在一条四面序列棱柱光路中，第二内部接口全反射，移除该
因子的配对效应为零；换为非参考、不对称上下锥及非均匀面距的四面序列后，第二内部
接口可在宽空间域贡献约 0.07 的短谱占比变化。实际最强色边却不位于该接口 kink
曲线的投影范围内。因此需要保留实际结构、条件曲线、有限支持和因子介入的不同
空间范围，不能把 `discriminant=0` 的像直接当成混合后色带的轮廓。

原生数值消费也有了研究证据，但尚未成为新公开 API：以现有 `TracePathChain`
模板配合独立验证过的二阶对偶数算子，能输出显式球面切基中的梯度与 Hessian，
经过研究 C 批量桥，由 Python 消费者执行临界点 Newton 求解。两种晶体的实际
捕获点对独立 JAX Hessian 的最大绝对误差约 `1.6e-11`，Newton 结果对独立解析
方向的残差约 `1.3e-13`。折射率和门函数导数在该研究桥中仍是原生双尺度有限差分，
不是 AD；不可用项没有由调用方差分填补。

这一原型还揭示了可用性边界：若门函数的差分也要求整条光路在扰动后有效，即使所求
的是较早内部接口的量，出口临界点附近也会因为末端门失败而拒绝它。已追踪的曲线
因此在出口 Snell discriminant 仍约为 `2.5e-5` 时被数值截断，而非真正走到物理端点。
“整体路径有效”和“某个局部字段可求值”不能在后续接口中默认为同一个谓词。

上述模块阶段尚未组成一般各向异性天空的共同发现器。后续二维纵切的新增证据见下一节：
共同入口和局部连续亮脊已接通，但稀支持的有效发现、一般谱域轮廓及完整机制配对仍是
产品化前的研究依赖。原生批量数值或一条开弧可用不消除这些依赖。


## 8. 二维纵切的进展与反例

一个研究入口现已将显式旋转测度、实际二维天空、亮域／谱域、连续局部亮脊、条件
机制和数值消费串联起来。例子包含严格片晶、双向 1° 高斯倾角加 0.265° 太阳盘、
以及非均匀面距的水平柱晶双均匀旋转支持；不是把 `D` 径向图换个坐标。它仍是
研究原型：光学、有限走廊、方向导数及新增球面密度求值在 C++，发现调度仍在
Python，不是公开 analytic API 或所有产品取向语义的实现。

### 8.1 重复误差、网格误差和局部残差是三个量

两份独立采样的差只有约 0.1%，仍可同时带着很大的离散偏差。同一 1° 观察尺度下，
球面格从 32,768 点增为 131,072 点，一组片晶图的局部峰值差达 19%。粗格上的
“负曲率＋小投影梯度”还把严格纬线附近偏出 2.757° 的区域叫作亮脊。

有效改法是让粗格只负责发现起点，再对真实样本的球面观察核作连续求值。研究原型
采用归一化 von Mises–Fisher 核，原生输出显式球面切基中的密度、梯度和 Hessian，
局部校正横向 log-density 的驻定条件，并要求法向负曲率强于切向曲率。这个
各向异性判据是声明的形态选择，不是“所有值得解释的特征”的定理；亮峰和宽带
须保留其他表达，不能因为不像线而删掉。

严格片晶的连续脊与独立 LI 前向积分的位置差在所核对的八点不超过 0.00085°。
其相对未平滑纬线约 0.003° 的偏移属于球面观察核，不能拿未平滑几何值充当同一量。
单场景从输入到局部校正的一次本机测量约 1–1.8 s；包含后续贡献关联、局部样本
充分性判据的柱晶场景约 4.4 s。局部求解残差不证明没有漏分量，也不替代谱域边界
或支持端点的精度证据。

### 8.2 条件搜索必须接实际贡献域

把所有其他旋转坐标固定到均值，可能完全找不到候选，但实际图中仍有亮弧。
从已发现脊线的实际贡献姿态出发，在活动坐标对上搜索原生方向 Jacobian 的
有向面积零点，水平柱晶实例得到 17 个独立 LI/JAX 核对的条件见证。
条件像与实际亮脊相距 0.234–1.385°，不应强行对齐；其 A、T、各接口因子和
在实际域上的配对反事实共同构成可检查的证据。还有 27 个查询未括到根，不能
写成“无机制”，更不能把有限的临界见证当成所有成因都已解释。

整体路径与局部字段的域也已分开验证：读取 `TracePathChain` 已到达前缀的
`ChainDomain`，可以在末端拒绝的 160 个实际邻域样本上恢复较早接口的梯度；
独立 LI 导数最大差约 `2.31e-10`。完整 D/A/T 和未到达接口仍不可用。
这一修复不需要复制传播公式，公开接口仍需准确表达逐字段可用性。

### 8.3 没采到、亮域分离与物理拓扑不能互换

水平柱晶高度改成 `1e-4` 的真实输入，两次各 1,024 样本都未采到支持；增到
262,144 样本后每谱各有八个支持点，独立有限几何确认捕获点的最小 A 约为
`2.15e-9`。所以空表只能说搜索未检出。反过来，两个稀样本结果偶合，也能让
局部重复误差假绿；局部有效样本量下限可拒绝假特征，但这只修复了状态诚实性，
**没有解决有效发现稀支持的问题**。所用 ESS 下限是研究启发式，不是置信保证。

同一柱晶图上两个主要亮结构之间，独立 LI 仍找到 68 个有效弱光方向。
低亮度掩码会删掉它们，因此图上或特征点图的分量数不是物理支持的拓扑证书。

### 8.4 原生数值的真实用途及剩余出口

一个 LI 风格消费者从自动发现的谱过渡域和原生分数梯度选择球面截线，查询同坐标
多谱／逐控制密度及切导数，测量声明的分数 0.2→0.5 过渡宽度。诊断两指数例子的
结果为 2.118646°，独立 LI 前向积分的两端位置差小于 `7e-10°`。调用方没有
有限差分补洞或重写光学；这是数值有实际研究用途的证据，不是该截线水平值成为
产品颜色判据的理由。研究数组保留和并发查询一致，也不替代正式安装树、版本、
`struct_size` 和 ownership 的验证。

仍未通过的出口必须继续保留：一般二维谱域的连续边界（当前大多仍为格域）、
稀支持的有效发现、未解释亮结构与所有支持／密度／逐接口非光滑机制的调度、
峰线分类与高阶／角点／原子／开放端点。实际产品分布、相关随机形状、完整谱、
明确成员和跨层组合也未由这些例子覆盖。后续支持感知、连续谱边和来源配对的
新增证据见下一节；它们沿用同一入口与原生数值桥，没有把一般稀支持或所有机制
的未解项写成确定性产品实施细节。


## 9. 支持感知发现的实测进展

### 9.1 提案可以改变，积分测度不能改变

对高度 `1e-4`、非均匀面距的水平柱晶，已核验的正支持姿态可以用来学习周期
重要性提案：一个全圆均匀旋转坐标用局部周期正态混合，其余坐标维持原测度，
并保留 10% 的全域分量。所有实际及去因子通道都乘回完整 `p/q`。65,536 个
样本中每谱获得约 6,300 个正支持点，而原无条件 262,144 个样本仅有八个。

独立 LI 验证不使用该提案或检测到的天空区域。对此具体挤出棱柱和两侧面之间的
直线段，两个面在水平面的最小间距为 `d`，柱高为 `h`，必要条件是
`|v_z| / |v_xy| <= h/d`。结合入口 Snell 的切向分量守恒，可以得到最后旋转
坐标的两个必要区间；保留其原测度后作独立张量积分。两谱总量差小于 0.014%，
八个连续亮脊点的独立法向极值修正小于 `6e-6°`。这个几何界有明确适用条件，
并不是所有光路的裁剪公式；它只作独立 oracle，没有成为发现器的名称分支。

没有外部正样本时，形状厚度延续也取得了局部证据：中间几何只训练提案，最终
仍对调用者的真实薄几何积分。在太阳高度 20° 和 31° 的两个输入中，各八级、
每级 4,096 个训练样本，最终每谱约一万个正支持点、两条谱轮廓；独立质量差
不超过 0.116%。训练本机各约 0.24–0.27 s，两个输入的训练、两档发现和谱边
精化合计约 7.7 s。它仍依赖可用的厚度延续和周期坐标，不是一般斜向高维薄域、
Gaussian-only 支持或极端形状的求解证明。

两次真实失败限定了判据：

- 两个独立 scramble 的 Sobol 序列按行拼接，会得到错误的联合分布，即使每个
  边际都正确。正常高度对照曾给出 0.0093 / 0.0880，而正确总量约 0.0219。
  把所有变量放进同一个更高维 Sobol 点才恢复；独立 seed 不能代替联合维度。
- 延续过程中，无权正样本重采样和按相邻种子距离设置的过窄带宽，会使一个
  模态消失。两档结果都稳定地少掉约 51% 的总量。按 `p/q` 及实际贡献加权训练、
  以占据模态内的圆周离散度设宽后恢复。全域提案密度大于零只保证理论测度
  没被截断，不保证有限预算不会漏分量。

### 9.2 连续二维谱界与三种边界

粗球面网格可以只提供谱分数水平的起点，随后由原生密度切梯度通过商法则
驱动球面预测—校正，追踪连续水平集。在同一非 Haar 二维倾角输入上得到一条
开放谱界，在薄柱晶上得到两条；0.5° / 0.25° 两档步长的端点几乎相同，
独立 LI 的端点位置差则最高约 0.0051°。二者分别量连续求解误差和积分误差。

这里的分数水平 0.35 / 0.65 是声明的研究观察量，不是通用颜色判据，也不是
实际 RGB。没有括到的水平不生成曲线；真正运行的等折射率负例返回零色边。
端点由谱分数水平与观察亮度下限的双方程求解，因此必须标为**观察掩码删失**，
不能叫物理支持边。闭合、交汇、梯度退化处和遗漏分量仍须单独验证。

另外，`A>0` 到 `A=0` 也不只有一种原因。实际贡献条件上的 46 个已验证端点，
有的因有限走廊面积消失，有的因整体光学域门失败。后一类中面积可以在门内仍
为正，不能仅凭 `A=0` 就标为几何轮廓。必须分开记录有限面积边、光学域边和
观察掩码边。

### 9.3 实际来源证据不以临界根计数为目标

在实际亮结构的位置，原生实际／去面积／逐接口密度 jets 可以直接比较法向
log-gradient、曲率和谱分数。非对称上下锥四面光路进入同一二维发现链后，
第二内部反射的同位置分数效应在两份采样中均为正，约 0.044–0.063；棱柱
四面光路负例在 24 个实际位置、两份采样中都严格为零。独立 LI 几何与光学
加上另一份球面积分实现，重算全部控制的差不超过 `2.1e-12`。这里复用相同
采样输入以检查实现，不把它当作独立采样方差证据。

所有已到达接口的判别式也从贡献姿态进入候选搜索，保留条件、接口身份、
有限支持及末端有效性。但条件 kink、同位置权重调制与唯一成因仍不是同一件事。
未括到 Jacobian 根不应强行补成 caustic，邻近支持端也不是因果证明。完整二维
姿态密度／约束机制分类仍未完成。

研究数值消费者继续可用：从自动谱轮廓选择法向，读取同布局的多谱／控制
密度 jets，得到 0.2→0.5 的角宽 2.19856°，独立 LI 为 2.19462°；没有让调用方
补写光学或有限差分。正式安装树、版本、所有权和成熟调度移入 C++ 仍属于产品
交付，而非这些研究数组自动具备的属性。较宽天空域的深路径发现本机已经需要
约 27–38 s，也不能把此前小场景的 1–4 s 当作所有输入的成本承诺。
