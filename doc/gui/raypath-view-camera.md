> 状态：**取证记录，尚不是获准实施的共享相机蓝图**。源码基线 `c1149fe20`，核对日期 2026-11-06。
> 已批准的产品目标是 Raypath view 与主图同源镜头、同交互、双向同步，纯观察不启动新 scan。

### 1.1 五类操作的条件对照

| 操作 | 立即效果 | 后续实际工作 |
|---|---|---|
| Fit | 有采纳图且正值可拟合才写中心/半径；来自**当前图的格值**，不是全天结构支撑证书 | 若键变：先旧图重栅格，再 settle、新 map、重新采样/求值、采纳。无结果/全零/键不变不新发 |
| Full sky | 总是写天顶/180°并记用户 steering | 已处同一键时不新发；中心原来不同即使半径已 180°，键仍可变（请求实际上都映成全天，身份比请求域更细）。改变时仍走完整 map 路径 |
| 裸图拖拽 | 改圆盘中心，旧图按天空锚定重栅格 | 手势中不新发；停止并 settle 后若键变，重新采样/求值。marker 拖动是另一输入臂，只改天空点 |
| 滚轮 | 改半径/中心（最小半径 1.5°，`analyze_map_view.hpp:50`）；只有画布持有 wheel 且方向有效时消费 | burst 合并到 settle 请求；达到钳位且键不变不新发。信息区 wheel 是滚动，不是缩放 |
| 首次 auto-Fit | 首个采纳图、该选择未尝试、用户尚未 steering 才运行 | 成功改变键会发生第二次完整 map；Fit 失败或用户已动则不发第二次。换类恢复这条默认链 |

**分层结论**：当前同时存在真正的显示重投影、CPU 重栅格和完整物理重求值；三者不是同义词。
删除视窗键只能阻止后两者中的请求臂，不能生成被丢掉的事件或补足窄窗覆盖。
「重复点按钮不扫描」成立的条件是键未变，而非点击去抖保证任意两个全天请求都合并。

## 3. 现有载荷的保留与丢失

| 产物 | 保存了什么 | 不能推出什么 |
|---|---|---|
| 最终 `MapResult` / C map handle | 当前视窗格的中心坐标、per-sr 类和、事件数、状态、帧轴；完整成员前缀/λ/n；独立点质量 | 细格内事件偏折/方位响应、窄窗外数值；计数不包含事件本身 |
| `BandSum` 局部 `SampleEvent` 列表 | 每成员完整 lattice 的正 A·T、u、phi、偏折/序号，未按视窗裁剪 | 现在不留在 workspace/result；即使保留也未预计算所有天空方位的姿态密度 |
| GUI RGBA 圆盘 | 截断/着色后的最多 512² 显示像素 | 原始量、奇点/域外与零的可逆区别、细弧数据、全空间覆盖 |
| geometry workspace slot | 名义晶体几何与索引 | 波长相关光学事件、方向密度或已求出的 class map |

结构证据：`src/raypath/results/reference_map.hpp:64–76` 是最终数值载荷，
`src/analytic/discovery.hpp:335–349` 是更上游事件；两者不应混称「全天结果」。
`MapResult` 冻结与读取仍须服从 [typed-results.md](../raypath/typed-results.md) 的只读完成值原则，
不能把第一次 getter 的列拷贝扩成隐式补算。

## 4. 表示判别：已证边界与未决路线

### 4.1 格值的信息损失

`BandSumOnEvents` 的 band 值（省略相同的归一化常数）是
`sum(w_i * rho_i(az_center), delta_lo <= delta_i < delta_hi)`。
只保存粗格的值与 k，无法反推出移动/缩窄后的区间和：例如同一粗 band 内两事件，权重
`(1,3)` 与 `(3,1)` 都给总和 4、计数 2，但只含第一个事件的新窄 band 分别给 1 与 3。
这是算子的非单射反例，**不是声称这两张小表来自 C01 的光学事件**；第 2 节的真实 C01
内缘读数独立说明细窗带来的空间分辨能力不是虚构。把旧全天格插值或把旧窄窗域外填零均不合格。

当前 GUI 最小直径 3° / 220 格，偏折步长约 0.013636°。若用同一步长的全天等角表，需
13200×26400 = **348480000 格**；仅一个 double 值列为 **2.596 GiB**，按现有三 double＋
int＋enum、假定 32 B/cell 的裸 cell 表为 **10.386 GiB**，尚无 C 投影列、索引、GL 或临时空间。
这些是字段布局与整数算术**推导，不是 sizeof/RSS/性能实测**。它超出现接口 262144 格上限，
而且等角网格在极区过密，不能用此数字否定球面自适应/压缩方案。
即便如此增密，也只接近固定步长：新格边界连续移动会改变事件归属，固定表仍不与直接窄窗逐值相等。
所以「提高一张全天纹理的分辨率」既无现成载荷支持，也不是精度闭合证明。

### 4.2 保留事件的真实能力

`SampleEvent` 是与视窗无关的上游数据；保留它可避免再次 `BuildEvents`，因而避免新的
lattice、路径光学与入口面积计算。但它**不是已经加权完的全天亮度**：

- random/均匀密度 `rho=1`：排序偏折、权重的前缀和可查询任意 band，不必重新遍历光学事件。
  有理数区间算术的六个最小对照精确相同；这只证明代数分离，double 前缀相减会有消减误差，
  不能直接承诺 bitwise/细格相对误差或低正值保留。
- column/plate/Parry/Lowitz：`band_sum.cpp:201–206,232–254` 的 `RowsOf(event)` 与
  `PixelRow(sun, centre)` 共同决定 `rho`，方位变化会重新计算权重。
  `pose_density.cpp:175–183` 实际调用 acos/高斯，含 roll 家族再调用 atan2/周期高斯。
  因而一条只按偏折累加的标量前缀不能回答任意新方位。
- 代数见证：sun 高度 20°，事件正交基 F=I，column zenith90°/std1° 时，方位 90° 的
  未归一化密度为峰值 1，89° 为 0.6430673183545461，0° 在 double 下下溢为 0。
  公共密度归一化相消；这里同样是**核函数依赖的代数见证，不是引擎生成的物理场景或性能测量**。
  生产支持定向分布的证据来自 [C16](../cases/raypath-analysis-cases.md) 与源码，不能用 random
  成功代替定向家族的质量证明。`scene_to_analytic.cpp:186–201` 将声明的 spread 直接交给密度校验；
  合法 std 只要求有限且大于 0（`pose_density.cpp:63–75`），没有可直接借用的「所有密度至少有某个角宽」下界。

保留所有事件的体量也须具名：按现有字段推导 72 B/event，12 成员 n=500k 全保留上界约
412 MiB，n=2M 约 1648 MiB。**这是全保留计数上界，不是实际 kept/RSS**，也没有证明必须采用
该布局；辅助索引与 RowsOf 可使内存再增。旧完整查询时间不能证明事件重放的交互时延。

### 4.3 路线裁定

| 路线 | 已证能力 | 不能据此通过的条件 |
|---|---|---|
| 只删视窗 key／拉伸最终栅格 | 能停止重复请求 | 细弧、窄窗外覆盖及新 band 信息缺失，排除 |
| 更密的一张全天表 | 可事先规定固定角分辨率 | 现接口格数不够；移动 band 等价性/表示误差、极区与首算成本未证，不能冻结为推荐方案 |
| 保存全部事件，再调用 `BandSumOnEvents` | 可免新的光学采样；按相同 cells 重放可使用同一估计器 | 是待检验的观察派生候选，不是已完成图的纯重投影；须按实际事件访问/重复量、精度、内存与完整交互成本判断。不能只因免 `BuildEvents` 判合格，也不能只因调用方向密度函数判不合格 |
| random 的偏折前缀 | 存在可分离代数结构 | 尚无浮点细 band 误差/特殊态/交互实测；更不能覆盖现已支持的定向族。不以只支持 random 缩减目标 |
| 事件范围索引＋预计算方位响应的自适应/压缩表示 | 是继续保留目标的研究候选；查询可只读系数，不再评估物理密度 | **未证可行**：须控制窄密度/细 band 的累计误差与前缀消减、支持任意相机 footprint、首算/内存/每次观察成本。没有旧测量可复用，不以算法名称代替这些证据 |

截至上述代数审计，只执行了算术判别与存储推导，没有新路线引擎时延证据。
这足以排除「现有结果只换投影」与「events 就是预先算好的全天亮度」两条捷径，
**不足以证明全部可能表示都不可行**。产品要求禁止观察重启光学采样/路径追踪、重建整类事件，
也禁止把完整 map 扫描藏进显示/getter；并非禁止一切方向密度/band 函数再次求值。
允许基于已有、身份与完成覆盖明确的产物进行有界观察派生；是否合格由实际工作量及质量/成本决定。
因此，保留事件与预计算响应均可被检验，前者并不需要 owner 先放宽产品目标；后者也不是唯一合法路线。
数据表示的关键精度/成本仍需在产品实施前取证，不能交给实施时临场定容差。

### 4.4 真实生产事件探针：质量保持，但直接重放未过交互筛选

2026-11-06，本工作树以 Apple clang 16 / Release `-O3 -march=native -flto=thin` 新鲜构建静态库，
隔离 native harness 调用未修改的生产配置解析、`PrepareGeometry`、`ResolveCrystalSceneScope`、
`ResolveWavelength`、`IceDiscovery::BuildEvents`、`MapPixelGrid` 和 `PoseDensity`。没有产品源码变化。
两臂均为规则 h/a=1 棱柱、sun altitude 20°/azimuth 0°、550 nm、n=500000、`3-5` 物理 PBD 12 成员：

- **C01 random** 来自 `test/e2e/configs/raypath_feature_random_regular.json`，只将 sun altitude 改为 20°。
- **C16 column** 来自 `raypath_feature_column.json`，sun altitude 改为 20°、roll 改为 uniform360；
  该 fixture 原为 gauss roll0/std5，不能将它原样称为 column-only。zenith90/std1 与 azimuth uniform 保持。
  这里只检验 column，不将结论外推到 Parry/Lowitz，也不将 Gaussian 可表达性等同产品 report 完备。

**候选及对照。** 每成员保留完整 sorted `SampleEvent` vector，一次建立 deviations 与非uniform 的
`EventRows`；观察 lower_bound 取 band 并用相同 double 表达式、同一事件及成员顺序求和。
这只去掉光学构造和重复行构造，没有近似或前缀消减。未修改的 `BandSumOnEvents` 是四窗的逐成员
全 `PixelValue` 字段 oracle；fine 窗另以新鲜 `EvaluateReferenceMap` 完整类调用核对 value/count/kept
及 12/12 完成覆盖。该完整调用**仅是正确性 reference，不重新计时旧查询**。同核等价只证保留/派生不变，
不证物理核独立正确；C01 另由闭式边锚核验，C16 另检查实际非零和方位响应。

| 质量/工作量 | 结果（两场景相同的访问计数；密度调用仅 C16） |
|---|---|
| 完整保留 | 实际 kept=959534，12 成员均完成各自 n=500000；两场景光学输入相同，密度不同 |
| fine：[20°,24°]×[−4°,4°]，200×400 | 全字段差异 0，完整原算子类和/count 差异 0；访问 173926 个不同事件，共 69570400 次，即每事件 400 次 |
| half-grid：同域 100×200 | 全字段差异 0；访问同 173926 事件，共 34785200 次，每事件 200 次；少格不等于保持原细节 |
| az-shift：[20°,24°]×[86°,94°]，200×400 | 全字段差异 0；同 69570400 次访问，C16 该窗真实零、不是拒答；C01 与原窗同峰 1.5596515 |
| full：180×360 | 全字段差异 0；959534 个不同事件共 345432240 次访问，每事件 360 次；不因最终显示相同物理场就免去重复 |
| 独立边/定向结构 | C01 闭式最小偏折 21.916126439800408°，fine 首正中心 21.91°（落在跨边 cell 内）；C16 fine 有 42000 正格、峰 69.2360215，非 random 的 1.5596515；full 有 9916 正格，不是两臂全零假绿 |

**成本筛选事前依据。** 手势须先立即反馈相机，主线程 60 Hz 单帧 16.7 ms；native 高质量派生的研究
必要线预登记为 100 ms（6 帧），给着色/上传还需留余量。这是研究用直接操作目标，**不是 owner 已批准的 H
产品预算**；过线仍不能签端到端通过，远超线则没有理由按此直接候选冻结蓝图。单活跃类保留＋索引研究线
256 MiB（本机 32 GiB 的 1/128，需容纳 sim、临时数据、GUI 及在途两代），也不是新增产品限制。

process CPU 与 wall 差距至多约 6 ms，故该量级不是单纯调度等待。没有测产品 GUI 输入到呈现时延。

密度求值。`Observe` 的静态调用闭包无 lattice/trace/事件构造，零新光学工作是白盒结构事实，
不是本探针对所有产品路径安装了动态计数器；免此工作并没有消除整图估值级别的重复。
保留成本在研究线内不等于响应成本合格。候选失败不依赖把 100 ms 当 owner 硬约束：
其秒级与 360–400 倍重复本身已反证「保留事件后只剩廉价重投影」的假设。

不扩特殊态或冻结后续实现合同。下一最小投资应对**同一批已捕获事件**检验范围聚合的方位响应表示：
先在 C01 用无近似范围和消掉列重复，在 C16 检验能否用带误差证据的范围节点响应压缩消掉每 event×cell
的密度重复，而不是继续只缓存行/重复完整事件重放。random 的增量不得冒充全族方案；C16 full 至少需
约 43× 的 native 时延改善才碰到研究必要线，微小常数优化没有继续冻结的依据。新近似必须在取数前
以实际 cell footprint/弱正值/细边和窄定向峰制定误差依据，不能丢尾或凭总量相似通过。
这里提供下一投入的可检验收益门槛，**没有证明压缩路线一定可行**，也不先把它写成 H 的产品任务。

### 4.5 结构范围响应探针：强域通过不等于弱域与零支持通过

同日承接 §4.4 的真实事件字段流与逐格 oracle，核对文件 hash、同一产品基线及本树静态库 hash 后，
只构建新索引，不重新采样/追踪，也不重新计时旧完整查询。事前登记了两个候选及质量门：

- **C01 正项范围树**：按偏折合并真实成员事件，以平衡树查询 `[delta_lo, delta_hi)` 权重和，避免
  普通前缀相减。只重排正项加法；按最多百万项串行误差的保守界，逐格 relative 门为 `2e-10`。
- **C16 分块方位响应谱前缀**：column 不读取 roll，保留事件偏折/权重/`RowsOf` 第三行，实测
  compact event 为 40 B；每 64 事件一块，在全周期 2048 方位直接求生产密度和、FFT 保留 0–512 模，
  再对块系数作前缀。任意 band 的完整块查系数差，两端不足 64 事件仍精确求密度，不量化 band 边界。
  512 模对理想 1° Gaussian 的衰减估算只支持开展检验，不是对真实响应/浮点下溢的误差证明。

本轮只检验 class map 的 value/count/singular，不声称成员 `k_eff` 或含 roll 家族已经通过。
C16 的事前质量门为：reference ≥该窗峰×`1e-8` 时 relative ≤`1e-6`，更弱正值 absolute ≤峰×`1e-14`；
**另须保持真实零和正号**，不得靠测后 clip 或改变阈值过关。两数值门在分界连续，强域门远细于线性
8-bit 显示的一步，但全局 absolute 误差不能代理零/弱正值语义。逐列另查峰 row 与半高宽，不只看总量。

| 结果/工作量 | C01 范围树 | C16 谱前缀 |
|---|---|---|
| 四窗 count / singular | 差异 0 | 差异 0 |
| fine / half-grid 质量 | 最大 relative `5.76e-16` / `6.54e-16`，正零/峰 row/半高宽均保持 | 最大 relative `1.22e-12` / `1.08e-12`，正零/峰 row/半高宽均保持 |
| full 质量 | 最大 relative `1.57e-15`，正零及逐列细节保持 | 强域最大 relative `6.69e-8`，但 2469 正格变负、488 零格变非零；72 列峰 row 改变，半高宽最多差 26 个原 row |
| az-shift 质量 | 数值及细节保持 | 原 42000 个非空 band 格都为零，却全部变非零：23056 正/18944 负，最大 absolute `2.20e-13` |
| fine 观察访问 | 443200 树节点，替代原 69570400 次事件访问 | 2600800 精确边界 density calls＋43050000 系数项 |
| full 观察访问 | 138600 树节点，替代原 345432240 次事件访问 | 638640 精确边界 density calls＋9963000 系数项 |

**新增失败根因是表示的动态范围与零支持，而非原来的整 band 密度重复。** 例如 full 的同一格，
原值 `7.729266212223277e-19` 变成 `−1.5528203557167835e-15`；原场还存在 `1.5e-323` 的正值。
全局正负谱重建与跨块前缀相减没有为这些弱值提供正性/零证书。strong-domain 与 fine 通过证明
不能把问题归为“所有方向都算错/全零”，但也不能用强信号的好成绩替代暗方位、细节和有限零语义。
az-shift 零峰使该窗按峰归一的 absolute 门为零；即便不使用这条边缘判据，full 的弱正变负已独立失败。
独立逐格回读的质量 gate 真实退出 1（`C16/az_shift`、`C16/full`），不是采集程序 exit 0 就算通过。

事前登记的“低响应格精确重放”补救也不能直接放行：按原 reference 的弱域选 full 的 6933 个非空格，
会重新访问 231347464 事件，约原 full 访问的 67%；真实零的 az-shift 全部非空格需 69570400 次，
回到原窗整扫工作量。仅按 candidate≤0 选择还会漏掉假正格。这是该 fallback 集合的**工作量诊断**，
不是所有算法的下界或耗时测量；支持证书可能减少访问，但本轮没有验证它，不能以“以后加”通过当前方案。

构造响应实际用了 **1965031424 次**生产密度求值。正确性运行记录 wall 21.036 s / process CPU
20.953 s，未独立负载准入，故只作构造诊断，不签性能预算或与旧准入时延比较。进程峰 RSS
341049344 B 含加载/FFT/JSON 等，并非表示净占用。质量失败后停止观察计时，不签 100 ms 研究线通过，
也不因保留 payload 小于 256 MiB 就签产品内存通过；GUI 着色/上传与双代峰值仍未测。

**裁定**：C01 已从代数可分离推进到真实浮点范围和；C16 证明结构聚合能消掉绝大部分观察密度调用，
但当前线性谱前缀不能作为合格全域表示。不是所有压缩表示均不可能，也不是可以缩成 random-only。
下一最小研究应先对这些同格失败输入检验局部归一的正值/对数范围响应及支持/下溢证书，
以少量真实节点的质量与存储/访问增长决定是否值得全量构造；不能只增加谱模数、clip、放宽弱值语义或
回退全域逐格重放。首次响应构造成本也须重新审计。关键项未证成前不扩大特殊态/其他密度家族，不冻结产品蓝图。

### 4.6 局部正值响应：动态范围可修，但局部通过不签全树成本

后续的最小局部判别继续复用 §4.4 的真实事件、生产转换密度及不可修改的逐格 oracle，生产源码、
构建输入和静态库 hash 均未变化。这里区分两个消费面：现有 C map 的原始 binary64/确定性合同不变；
候选是在相同 cell footprint 下派生显示量的近似，不以「所有跨 300 数量级值逐位相等」作为新增产品要求。
正常正值的局部 relative 门为 `1e-6`：任一暗方向独立归一后仍远细于线性 8-bit 的一步；次正常正项和
另留 `16*N*denorm_min` 的量化下限。零/正号仍须保持，不按候选成绩调整阈值，也不将局部归一变成噪声放大器。

候选改为**正项范围树的分段 log-cubic 响应**，不使用全局正负谱或跨块前缀相减。每节点的区间由真实
事件第三行 `t = C + A*cos(az) + B*sin(az)` 的解析极值界定：

- 全部事件在区间内的最大生产贡献都下溢为零，才允许零段；Gaussian 本身没有紧物理支持，
  此处证书是原核的**数值下溢零**，不是物理不存在或拒答。
- 正项和有正常数下界时，在局部 log 域插值再 exp，避开强响应的谱残差覆盖弱响应。
- 只在已界定的次正常尾段精确访问该节点事件；其访问量显式计入，不把暗域全部退回逐格重放。
  log 与精确尾段的合法域有重叠，不能在同一阈值两侧留一条未覆盖的缝。

选取原 full 谱失败格中的正变负、超弱正常、次正常，以及 az-shift 的非空零格；再取原失败格中事件
band 最大的一格检验较大节点。得到 5 个真实对齐节点，规模为 256、2048、16384 事件。它们是失败域
偏置取样，**不是全树平均或全状态覆盖**。每节点的 5456 个独立留出角包括原四窗列中心与 4096 个非
构造节点方位；零/正号、正常值相对误差及原列中心的峰位/半高宽均通过，最大 relative `9.92e-8`，
留出正项和最小达 `8e-323`。5 个捕获格局部替换后均保持零/正和数值门，例如原
`7.729266212223277e-19` 得 `7.729266216444982e-19`；这是局部替换诊断，不是全图性能证据。

首次局部采集中，点值全绿却有每节点 4 条极窄 unresolved 区间：log 与尾段使用同一切换阈值，在阈值
根处不能有限收段。构造元数据检查据此真实拒绝，不以留出点未命中宣布覆盖。修订只扩大精确尾段的合法
计算域、形成重叠，没有放宽误差/零正门；重验后所有 5 节点均无 unresolved。独立 NumPy 从归档字段
重建行/方向，额外检查 62017536 个事件×角位置，区间越界为 0，谐波与几何表达差最大 `3.34e-16`。
这是采样反证检查，不冒称 libm 的形式区间证明或连续全域插值误差证书。

局部实际为 **296–519 段/节点、56 B/段**，vector capacity payload 为 28672–57344 B/节点；
保留 5 节点合计 172032 B。尾段实际读取 134、130、330、346、326 次，分别触发 34304、266240、
84480、708608、5341184 次事件访问；不是零成本。最大节点构造用了 128565248 次插值采样密度求值和
32964608 次上下界密度求值，暴露首算重复增长。128 事件叶层对应 7490 个完整对齐内部节点；扣除事件
capacity 后，256 MiB 研究线给内部节点的平均额度约 30239 B。局部容量已接近该额度，但不能将偏置
样本均值乘全树当实测或下界。全树保留/构造和完整观察成本仍须带上限验证，未签 100 ms、端到端交互
或全密度可行；尚不能据局部成功冻结蓝图。

### 4.7 全树增长判别：局部数值收益不能代理表示体量

局部质量通过后，先登记完整构造的内存停止线，再沿同一节点实现扩展；不是另铺全天 pixel 表。
叶层为 128 事件、内部节点从 256 事件起，按大小分层构造全部对齐 range；每节点压紧 vector capacity，
保留量计入实际事件、完整 Node vector capacity 和段数组，不用失败域样本均值外推。构造工作另受
500 亿次密度调用的研究投入上限约束；这个投入上限不是产品首算预算或性能通过线。

**实际先撞内存线。** 仅构造最底层所需 3748 节点中的 **3708 节点**，即全部 7490 内部节点的约一半，
就停止于 `retained_payload_over_256MiB`：

| 实测量 | 结果 |
|---|---:|
| 事件 vector capacity | 41943040 B |
| 完整 Node vector capacity（7490×64 B） | 479360 B |
| 已构造段数组，logical = capacity | 226086112 B |
| 已构造段数 | 4037252（zero 10194 / log 4011889 / exact 15169 / unresolved 0） |
| 保留 payload 合计 | **268508512 B = 256.0697 MiB**，超线 73056 B |
| 实际每节点段数 | 296–1753，均值约 1088.8；不是局部 296–519 的范围 |
| 构造密度调用 | 插值 16363877376＋界计算 4073394176 = **20437271552** |

独立回读核对段数×56 B、各容量加和、所需节点总数及停止条件，gate 真实退出 1；native 退出 0
只表示记录了预定停止。这个体量不含临时 harmonic 数组、JSON、分配器开销或未来 GUI/双代，不能当 RSS。
当前编码每节点从 32 个方位段起且不合并；剩下 3782 节点即使每个只有 32 段，也至少再需 6777344 B，
完整保留下界为 **275285856 B**。这是**当前编码/物化算法的下界**，不是其他压缩/稀疏层级算法的下界；
特别不据此断言紧凑编码、跨节点复用或选择性物化全部不可能。

此次新增根因是**全层级响应物化的非均匀存储增长与首算重复**，不是谱动态范围失败重演：局部正值/零
恢复确有证据，但靠低偏折的几个失败节点不能估计其余节点的角向复杂度。已构造节点没有 unresolved，
也不等于完整树/全图数值已通过；停止发生在任何完整观察前。构造诊断 wall 374.747 s / process CPU
286.182 s 未做独立负载准入，仅记录此次运行，不签性能比较或产品首算预算。

**裁定**：淘汰当前“每个内部 range 独立保存整周 log 响应”的具体表示，不扩特殊态/其他密度家族，
不跑无意义的观察计时，不签 100 ms。下一次投入若获准，应先复用已有捕获格/原始 grid 边界，做无需
新密度求值的节点访问需求与字节预算审计，检验紧凑/非均匀物化能否在真实 footprint 下同时留下存储及
精确访问余量；没有可行预算再铺完整树不值得。现有逐层/每 256 节点账本可回读，但未保存每节点的完整
模型/成本表，不声称已经有可直接续接的完整缓存或逐节点 Pareto 前沿。候选、预算与下一投入仍需裁定，
不将这些未决项交给产品实施临场优化，也不因本次失败撤掉同源相机的目标。

### 4.8 零新增密度的访问需求审计

2026-11-07 的前提复审不再要求每次观察取得任意新 footprint 的最高精度。批准的产品边界允许
显式质量更新；因此先复用 §4.4 的真实事件、四窗原始格边界与 §4.7 增长账，**不调用任何新 density、
BuildEvents 或 trace**。三份既有 manifest 的 22 / 21 / 48 项 hash 全部相符，生产库仍为同一构建。
按生产四角 band 的半开区间、959534 个真实排序偏折，以 128 事件叶块分解对齐 range；各有效格
的计数与原 oracle 全部相同，全天访问量还独立核为 `959534 * 360 = 345432240`。

| 原查询 | 不同非空内部响应节点（≥256 events） | 含 128 叶块的节点访问 | 两端不足 128 的精确事件访问 | 内部节点最小编码字节 |
|---|---:|---:|---:|---:|
| fine / az-shift，各自 | 275 | 152400 | 5263200 | 492800 |
| half-grid | 191 | 48800 | 1326000 | 342272 |
| full | 167 | 69840 | 1260720 | 299264 |

最后一列仅为每节点 32 段 × 56 B 的**当前编码下界**，不是模型实测体量。两端访问也不包含
128 事件叶块若未物化时的额外展开；例如 fine 另有 106 个不同的 128 叶块，不能把它们当免费节点。
四窗合计只有 **484 个不同内部节点**，远少于全层级 7490 个；fine 与 az-shift 同偏折范围却要求
不同方位，计数重用不等于密度响应重用。原四窗的 31 / 106 / 54 个不同精确 range 也不穷举未来
连续相机需求。没有逐 node 模型/成本表，不能将局部五节点均值乘以 484 当实测存储或性能。

**裁定**：旧全树失败不排除选择性物化，但显示目标并不必然需要连续响应函数。访问稀疏性留下研究
自由度，不构成继续投入的必要性；先检验下一节冻结全/细结果路线。若该路线满足目标，就停止响应树
研究，不为“完整”补算没有消费方的节点。

## 5. 复用与诚实性：继续设计时不能丢失的边界

此处是研究路线的准入条件，不改变现有 API 行为，也不宣称目标表示已存在。

| 变化 | 可复用性/真正失效的依据 |
|---|---|
| lens、姿态、FOV、roll、visible/front、画布宽高/DPI | 不改变冻结场景的物理输入；合格表示应只派生显示。最终旧 map 却受原域/格限制，不能据此放大其有效范围 |
| 换类、成员展开/对称条件变化、名义几何或 λ/折射率变化 | 光学事件/成员和失效。选择身份必须含捕获场景与分析代，不能只比类行文字 |
| 朝向密度变化 | 旧带密度的全天表示失效；即使某些纯光学事件可复用，也须按真实类成员重新核定，不能复用旧 weighted field |
| 太阳方向或捕获场景变化 | 要重新核定帧、响应与类身份；不把 live 编辑后的太阳与冻结结果的太阳混用 |
| n/质量更新 | Fibonacci lattice 随 n 改变，旧事件不是新档的完整前缀；需要显式的新计算及新完成身份，不能在观察中偷补样本 |
| 分隔、关窗重开、工作区切换 | 本身不是数据变化；不能清查询绑定或重新计算。窗口开合也不应承载缓存寿命 |
| 预算/取消/迟到结果 | 不是新的物理场景，但改变已完成覆盖事实；只能使用有证据的完整成员前缀，不把中断成员混入，不将旧代结果以新相机缓存身份采纳 |

非有限/不可用不是零：finite zero、域外未知、奇点 NaN、拒答、partial 与 point mass 必须独立保留。
太阳/对跖附近的 band 奇点不能插值桥接。rank-0 质量 m 与方法/误差要单独保存；改变显示 cell 时
其 per-sr 值是 m/Omega，不是拉伸旧 cell 的数值，屏外质量也不等于质量为零。混合类不能只画质量而丢带状臂。
这些语义由 [reference-map.md](../raypath/reference-map.md) 的 Units/Execution 节承载，不能在 shader 里另造物理口径。

若未来证明新表示成立，物理数据仍归 engine/raypath，GUI 只通过 engine capability C API 消费；
不能从 GUI include `analytic/`/`raypath/detail/`，也不为一幅产品图另开库或绕过产品 API 直连 analytic
公开库。依据是 [analytic-api.md](../interfaces/analytic-api.md) §2 及项目 GUI 边界。
只读结果必须持有自身完成数据，borrowed 指针的有效期不能依赖已销毁的 Workspace/Scene，
参考 [typed-results.md](../raypath/typed-results.md) 的 Completion/Ownership 及
[capi-lifecycle-architecture.md](../interfaces/capi-lifecycle-architecture.md) §9 的独立持有原则。
保留/构造表示是显式执行，不放到 getter/序列化/换相机时隐式启动；此处没有新增 ABI 声明。

## 6. 设计暂停边界与待裁定项

**结论：现有载荷不充分已经有证据；完整目标尚未被证成，不是已证明不可能。**
不冻结共享相机的后续完整合同，也不把产品实施当成带未知精度/成本的探索。

已批准而继续保持的方向：唯一相机权威、双向同步、观察不 scan，不允许独立相机、手动 sync 或默认关闭开关。
既有相机输入是 `BuildPreviewViewProjFromRenderer`（`preview_renderer.hpp:481–496`）；有效 roll/front
规则、Look At 写入纪律仍服从 [gui-state-governance.md](gui-state-governance.md) §2。
主图不同宽高比使用同一 lens/FOV 规则，不要求画同一像素矩形。globe 的对跖中心、固定可视冠及有效 roll=0
是现有约束，不能当自由参数。以上是继续设计的输入，**不是双方相机已经统一的事实**。
Fit/Full sky/首次 auto-Fit 的最终去留、全镜头映射示例与拾取合同尚未冻结；没有把当前圆盘手势复制成第二权威。

空间约束不因数据表示难题而退回重排：沿既有 Analyze 三观察层、D3/自由窗、稳定操作区/状态位/报告内滚方向；
不恢复被否的 master–detail/docking 形态。Pose & trace 仍需显式开窗，导航交付与相机/表示解耦；
这里没有用「讨论了入口」宣称导航功能已完成。

2026-11-06 的工程裁决已撤销「所有物理函数都不得再次求值」这一额外禁令。
§4.4 的首轮真实核判别显示直接重放质量保持，但逐 cell 重复仍使 C16 native 观察达 0.9–4.3 s。
随后批准的有界结构研究已在 §4.5 记录：C01 范围树通过质量门，C16 谱前缀消掉大量重复却在弱正值、
数值零与暗方位细节上失败。§4.6 的局部正值/下溢证书判别恢复了这些局部质量，§4.7 扩展到完整层级时，
尚未完成底层就超过 256 MiB 研究必要线。此次停在表示体量/构造增长，不是再次用函数名称、跨 300 量级
逐位相等的额外要求或缺测本身停止，也没有将全部算法裁为不可能。
下一研究投入应先裁节点访问需求与字节预算，不继续盲铺同样的逐节点整周响应；由 owner 选择是否值得
做该有界审计，不自行扩大为产品工程、重跑已得 oracle 或用 random-only 改目标。当前未取得完整正值树的
逐格质量/观察时延，也没有连续全域的插值误差证书；后续合格才扩太阳/对跖/接缝、C15 rank-0、
partial/refusal、Parry/Lowitz。不将 100 ms/256 MiB 研究必要线伪装成已批准的产品端到端预算。

未闭合项：全密度表示质量/交互成本、最终共享相机行为、后续产品实施的精确质量/成本 AC、
完整蓝图的独立文档实现评审。已完成机制审计与局部反证不等于设计交付完成，
尤其不等于用户反馈中的“不因观察重扫”和“相机同源双向同步”已经交付。
