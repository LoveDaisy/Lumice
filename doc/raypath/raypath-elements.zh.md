# 元素代数：D6h 群成员、三视图与局部类

本文记录引擎的逐元素对称代数——每个 D6h 群成员三视图（标签置换、姿态补偿、天空作用）的闭式推导、逐元素测度保持条件及其到既有逐位族判据的归约，以及它们服务的局部类定义。生产接口是 `src/core/crystal.hpp` 的 `CrystalElement`；三视图测试（`test/unit-correctness/core/test_crystal_element.cpp`）与光学见证（`test/unit-correctness/analytic/test_element_optical_views.cpp`）钉住本文每一条公式。

读者：触碰 `CrystalElement`、局部类解析或姿态补偿的贡献者。逐位 P/B/D 语言见 [raypath-symmetry.md](raypath-symmetry.zh.md)；本文是它下面的一层。

---

## 1. 为什么是元素，不是位

P/B/D 位与逐位门（`SymmetryGating`、`DeriveSymmetryGating`）命名的是群**生成元**。局部等价类是整群**元素**作用下的轨道，而起作用的元素常常没有任何位模式能命名：复合 `B·σ_a` 是绕水平轴的一个正常半圈，标签作用混合了 D 的棱面反射与 B 的基面/锥环互换，姿态补偿同时反射 roll 与 zenith。在 Parry 的 −52° 切弧侧，把 4-2 与 8-1 归并为一个物理类的是 `B·σ_0`——不是 B、不是 D、也不是任何位对——因为 B 单独与 D 单独的补偿公式描述的姿态映射与复合不同。

实现据此采纳的公理：

- 局部类**逐元素**计算；绝不投影回 P/B/D 位，位的列表/过滤语义原职不动。
- 复合元素的测度保持必须整体判定（§4）：它的三个合取支恰好是既有逐位判据的成分，但「B 适用」或「D 适用」任一单独成立都不蕴含复合保持（反之亦然）。

## 2. 约定（全部读自引擎，非假设）

- 姿态：`R = Rz(azimuth − 180°) · Ry(−zenith) · Rz(roll)`，行主序 body → world（`single_path_analysis.hpp` 声明的合同）。
- 面法线：棱面 `3+i` 在晶体系方位角 `i·60°`（`kHexFaceCos/Sin`），基面 1 在 `+z`、基面 2 在 `−z`；**面 3 法线在方位角 0**——下面每条公式都锚在它上面。
- `σ_a` 是方位角 `a·30°` 的竖直镜面，棱面指标 `i → (a−i) mod 6`（即 `MirrorFaceIndex(i, sigma_a)` 命名的平面）。`B`（σ_h）是水平镜面 `diag(1, 1, −1)`：基面 1↔2、锥环 13..18 ↔ 23..28、棱面不动。
- 角度均模 360°；下面的闭式角式在规范天顶图 `zen ∈ [0°, 180°]` 上陈述。退化图（zen = 0° 或 180°，azimuth 与 roll 不唯一）在矩阵层处理——生产接口（`CompensatedPose`）返回矩阵，角式必须**在极点也**与矩阵一致（§6）。

## 3. 共轭陷阱

值得写下来的一次推导错误：对**正常**的 `g`，`g · R_axis(θ) · g⁻¹ = R_{g·axis}(θ)`——共轭保角。对**不正常**的 `g`（镜面），转角翻转：

```
g · R_axis(θ) · g⁻¹ = R_{g·axis}(−θ)     (det g = −1)
```

有用的推论（F_y = diag(1,−1,1)，方位角 0 的竖直镜面；σ_h = diag(1,1,−1)）：

| 共轭 | 结果 | 读法 |
|---|---|---|
| `F_y · Rz(θ) · F_y` | `Rz(−θ)` | 轴不动（平面含 ±z），角翻转 |
| `F_y · Ry(θ) · F_y` | `Ry(θ)` | 轴翻成 −y 且角翻转：两者抵消——**F_y 与 Ry 交换** |
| `σ_h · Rz(θ) · σ_h` | `Rz(θ)` | 轴翻成 −z 且角翻转：抵消——**σ_h 与 Rz 交换** |
| `σ_h · Ry(θ) · σ_h` | `Ry(−θ)` | 轴不动，角翻转 |

口诀：**包含**旋转轴的镜面与它交换；垂直于轴的镜面反转旋转。（F_y 的平面是 xz 平面；y 指向平面外，F_y 把 y 映到 −y，仍在同一条轴线上，而不正常的角翻转把 `R_{−y}(θ)` 变回 `R_{+y}(θ)`。）丢掉这个翻转曾产出一个多出 ±180° 的 σ_a 补偿，与 `ComputeSigmaA` 和 B 条款的「roll plays no part」双双矛盾——修正后的推导逐字复现两者（§4、§5）。

## 4. 五族元素：各三视图

D6h 有 24 个元素；引擎以五族命名（`CrystalElement::Family`），记 `ψ_a = a·30°`、`φ_s` 为太阳世界方位角：

| 族 | 矩阵（晶体系） | det | 标签作用 | 姿态补偿 `T_g` | 天空作用 `σ_g` |
|---|---|---|---|---|---|
| 恒等 | I | +1 | 不动任何面 | 不变 | 恒等 |
| `P_k` | `Rz(60k°)` | +1 | 棱面指标 `i → i+k`（基面不动） | `az`、`zen` 不变；`roll → roll − 60k°` | 恒等 |
| `H_a` = `B·σ_a` | `2ûûᵀ − I`，`û` 为方位角 `ψ_a` 的水平方向 | +1 | 基面 1↔2；棱面 `i → a−i`；锥环互换 | `az → az + 180°`；`zen → 180° − zen`；`roll → −roll − 60a°` | 恒等 |
| `σ_a` | `Rz(60a°)·F_y` | −1 | 棱面 `i → a−i`（基面、锥环不动） | `az → 2φ_s − az`；`zen` 不变；`roll → −roll − 60a°` | 太阳竖直镜面 `M` |
| `S_k` = `σ_h·Rz(60k°)` | `diag(1,1,−1)·Rz(60k°)`（k=3：反演） | −1 | 基面 1↔2；棱面 `i → i+k`；锥环互换 | `az → 2φ_s − az + 180°`；`zen → 180° − zen`；`roll → roll − 60k°` | 太阳竖直镜面 `M` |

`M = Rz(2φ_s)·F_y`：平面包含太阳的世界镜面。只有固定入射光的反射才能把镜像场景变成同一场景——这就是不正常补偿 `R' = M·R·gᵀ` 唯一可行、且不正常元素移动天空点的原因：兄弟成员在 `M(q)` 处承载原成员在 `q` 处的光。

推导使用的关键恒等式（均由 core 测试在矩阵层验证）：

- `Rx(π)·Rz(γ) = Rz(−γ)·Rx(π)` 与 `Rx(π) = Ry(π)·Rz(π)`——H_a 的化简。
- 规范自由度 `Rz(A)·Ry(B)·Rz(C) = Rz(A+π)·Ry(−B)·Rz(C−π)`——天顶规范化。
- `σ_a·Rz(60k°) = σ_{a−k}`——五族封群的缘由（1 + 5 + 6 + 6 + 6 = 24）。

### 4.1 补偿为何是这个形状

两个体制背后的等变式，一次说清：晶体系迹线满足 `T(slots_g, g·u) = g·T(slots, u)` 对每个元素成立（晶体 `g` 不变；有效迹线的 g 像就是重标序列的迹线）。于是正常 `g` 在 SO(3) 内补偿：取 `R' = R·gᵀ`，兄弟的体框架入射方向是 `g·u`，其世界射线与原射线逐段重合——同一天空点。不正常 `g` 无法独自留在 SO(3) 内；世界镜面 M 恰在固定太阳时修复行列式（`det M · det gᵀ = +1`），兄弟的世界射线以镜像形式出现——同一射线模式、被反射、在镜像天空点。

## 5. 逐元素测度保持

`μ∘T_g = μ` 沿 `T_g` 的三个角槽分解，每个合取支都是既有闭式判据——不需要新的族规则（实施前假设，在此证实）：

| 条件 | 由谁提出 | 既有判据 |
|---|---|---|
| 方位角全周均匀 | az 平移（`H_a`）或 az 反射（`σ_a`、`S_k`）——**`P_k` 不提出方位角条件**（其 `T` 不动方位角槽） | `IsFullTurnUniform(azimuth)` |
| 天顶关于 90° 对称 | `zen → 180° − zen`（H_a、S_k） | `IsBApplicable` 的天顶合取支 |
| roll 平移 −60k | `roll → roll − 60k°`（P_k、S_k） | roll 满周均匀（`IsPApplicable`）；极点折叠胶合保持 k=3 半圈（`GluingRetainsHalfTurn`） |
| roll 关于 −a·30° 反射 | `roll → −roll − 60a°`（H_a、σ_a） | roll 锚点命名 `σ_a`：`ComputeSigmaA(roll mean) = a` 恰是这条陈述 |

反射半部的三条精确性规则与一处刻意分层差异：

- 中心对称的 roll 族（Dirac、uniform band、Gaussian、legacy Gaussian、Laplacian）恰好保持以自身中心为不动点的反射。**kZigzag 一律拒绝**：其声明律 |A·sin(t)+B| 没有关于任何中心的反射对称证明（B=0 时甚至单侧支撑——+A 处正密度、−A 处无支撑）。旧的逐位 D 答案保留自己的类型擦除锚点检查——冻结的过滤近似——故 kZigzag roll 上逐位 D 与逐元素答案刻意不一致：位服务旧消费者逐位不变，精确层拒绝其证明不了的。
- 作用 `roll → −roll − 60a` 亦可分解为「平移 s 后关于 c 反射」，凡 2c ≡ s − 60a（mod 360°）；测度保持该元素当且仅当存在某个分解的两半都保持。s = 180° 分支正是保留清单**对复合闭合**的来源：σ_0·P_3 = σ_3 在极点折叠轴上保持（折叠平移 180°、关于锚点 0° 反射），尽管其规范中心 −90° 什么也不命名。清单对 24 个成员枚举到不动点，局部类轨道与其运输事实消费的是一个真正的子群——每个类成员的载体一步把它映到代表，且逐成员可验证。
- s = 180° 复合也救不回来的 roll 反射（中心既不命名 −ψ_a 也不命名其平移伙伴）保持拒绝；漏并安全，错并不安全。

测试钉住的两条结构性警告：

- **复合整体判定。** H_a 的保持 = (az 均匀) ∧ (zen 对称) ∧ (roll 关于 −ψ_a 对称)，三者同时。B 单独不动 roll、σ_a 单独不动 zenith；任一单独的适用性都不蕴含复合的。
- **保持不是准入。** 测度保持的不正常元素仍移动天空点，它进入 `q` 处的局部类还须 `σ_g(q) = q`（`ElementFixesSkyDirection`）。Parry 轴保持 B（az 均匀、zen 关于 90° 对称、roll 不动），但 B 不加入任何 ±52° 类——因为 ±52° 不在太阳竖直面内。

工作场景（验收案例在本代数下的复述）：

- **Parry**（az 均匀、zen 高斯 90°±1°、roll 高斯 0°±1°）：保持元素 = σ_0、H_0、B/S_0；一切不正常元素因天空作用退出 ±52° 类。−52° 处的类是 H_0 轨道 {4-2, 8-1} 与 {4-1, 8-2}；有光的是 {4-2, 8-1}，字典序代表 4-2。
- **柱晶**（az 均匀、zen 锁 90°、roll 满周均匀）：P_k 与 H_a 全保持；切弧对 3-5/3-7 的十二个字面成员构成单一轨道，字典序代表 3-5，且因 `G_q` 在此与 q 无关而沿弧稳定。
- **板晶**（az 均匀、zen 锁 0°）：一切带 `zen → 180° − zen` 的元素不保持，故太阳两侧各自的类是单成员；两侧由 σ_a 联系——恰是「每侧由一个成员承载、两侧积分能量相等」这句话。

## 6. 精确性：何为逐位相等，为何

- 轴在方位角 0 的网格/见证元素（H_0、σ_0、P_3）对方向的作用是精确符号翻转，而面法线表取值于 ±1、±1/2、±√3/2——IEEE 精确常数。链上每个点积逐项变号、求和顺序不变，故偏差网格恒等式 `D_{gP}(g·u) = D_P(u)` 与 H_0/σ_0 世界射线见证**逐位成立**（analytic 测试断言相等，非容差）。
- 30° 相位轴的元素（H_a、σ_a，a ≠ 0）把 √3/2 带进矩阵；其恒等式以 1e-12 运动学带约束，不逐位。
- 天空作用判据的 1e-12 带是方位回绕的舍入余量（sin(±π) 与 sin(±2π) 舍入到 ≤ 2.5e-16），不是物理容差：真实的 1e-9 弧度离面方位角读出 ≥ 1e-9·cos(altitude)，高出带五个数量级。

## 7. 搬运对应与密度比的作用域

补偿背后的等变性对**每一个**元素成立（保持与否无关）：proper 载体 h 满足 h·m = r 时，姿态 `R·hᵀ` 让参考晶体 r 实现成员 m 在 R 处的同一世界射线。保持判定决定的是两个姿态承载的测度权重是否**相等**；搬运本身只需要几何。点面的密度比参考用的正是这件事：把请求成员映到参考成员（库存固定顺序的首个 proper 元素——确定性），落出搬运姿态，逐点复核世界射线恒等（有效性加出射方向一致），再报告同一声明测度在搬运姿态处的 log 密度与逐点 log 比。作用域是具名的姿态对，绝不是成员级上界；姿态偏离测度锚点几十个 σ 的成员在线性 rho 下溢为 read-as-zero 0 处仍保有有限的大负 log——log 形式的 −inf 只留给离支撑与 Dirac 切片，双方均离支撑是不可比（NaN），不是零。仅不正常元素可连时回答的是另一个问题（σ_h 移动天空点），按拒绝处理而非静默作答：跨镜面不存在同点比率。

## 8. 本层不主张什么

- 保持判据按元素、对本仓库的分布族陈述；新的分布类型扩展合取支表（逐位判据自己的 switch），不改本文代数。
- 局部类**定义**与轨道/命名机制在上一层（raypath 模块）；本文与 `CrystalElement` 提供那些层消费的逐元素事实。
- 本文没有采样陈述：每条公式都是闭式，网格/见证层之上的测试都是纯代数。
