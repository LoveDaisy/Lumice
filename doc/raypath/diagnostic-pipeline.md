## 2. 结果对象空间

### 2.1 五个位形对象 + 一个正交色度层（owner 确认 2026-10-17）

诊断输出按「5+1」组织。最初的提案列了七类对象；经 owner 两处修正收敛如下——每类有唯一
机制归属，无重叠。

**位形对象（5，几何层）**：

1. **源像 / 族坍缩点**（方向恒等或固定变换；映射 rank 0）
2. **一维常规像**（族维度产生，线通量按天空速度加权）
3. **焦散亮缘**（受限映射的临界像；可带边界重合标记）
4. **二维亮域**（含 ρAT/J 权重剖面——「暗区解释」住这里）
5. **支撑集**（边界 + 洞 + 边界机制标签；吸收原提案的「支撑边」「硬暗洞」两类，论证见 §2.2）

**色度层（正交，不占第七类）**：色偏只有两个机制来源——**位置色散**（临界像/边界位置随 λ
移动，各波长的边/峰堆叠出色分离；等效楔角存在时出现）与**权重色偏**（同一位置的 ρAT 随 λ
变，主力是近 TIR Fresnel 增强）。空间形态（边缘/条带/整体）不引入第三种机制，只说明挂载点
不同。故色度是与位形对象正交的一层，可挂在任何位形对象或全场上：

| 形态 \ 机制 | 位置色散 | 权重色偏（近 TIR / Fresnel） |
|---|---|---|
| 边缘色（挂支撑边/焦散亮缘） | C01 22° 红内蓝外、C09 ~149° 红边 | C06 149–150° 蓝边（部分）、C12 兄弟链同点色偏 |
| 条带/区域色（挂二维亮域/暗区） | ——（暂无语料实例） | C02 反日侧宽 TIR 色倾向区、C18 ~85° TIR 份额渐变带 |
| 整体色（挂源像/全场） | ——（暂无语料实例） | C15 日盘略蓝、C17 反日聚集略蓝 |

**编码进对象定义的两条纪律**：

- 色度层有**独立的最小触发条件，不随位形分析早停消失**（C14/C15 教训）：源像早停后
  weight_tint 腿照跑（survey 文档的恒等臂即如此——两次平行内反射把 Fresnel 系数平方，
  蓝端趋近 TIR，日盘因此偏蓝）。有楔角线索 → 查色散；有近 TIR / ESS 或噪声变化线索、或用户
  追问 → 查权重。
- **色散与权重的计算路径不同**（多 λ 重跑位置分析 vs 固定几何谱积分 ρAT），输出分开陈述，
  不合并成单一色偏字段。C06 蓝边是两机制在同一挂载点叠加的注意例：TIR 判据含折射率，
  TIR 圆位置本身随 λ 移动（位置色散分量），叠加近 TIR 权重增强（权重分量）——输出应拆开。

### 2.2 支撑集：为什么吸收「支撑边」与「硬暗洞」

本模型的物理是标量、正贡献、非相干叠加——一个方向变暗只有两种可能：

1. **支撑外**：没有任何正测度的正权重姿态映到该方向（preimage 空或零测）；
2. **支撑内权重凹陷**：preimage 正测度，但 ρAT/J 积分小。

无第三种（无相消、无负贡献）。因此观测词「软暗洞」必然分解为两者之一或两者的边界混合，
没有单一机制定义，**不设为原语对象**。「支撑集（含边界与洞）」是唯一几何对象，要素：

- **边界曲线**，逐条带机制标签：走廊关门（有限晶体 A=0）、出口 TIR 截止、密度/族的支撑
  截断（紧支撑测度或理想受限族边界）、光学有效域边界；
- **「与焦散重合」标记**：min/max 偏折 fold 恰好坐在支撑边上（22° 内缘、C09 ~149°）——该
  标记预测边上的亮度行为（锐亮边 vs 缓暗切），是 C01 锐边与 C03/C06 软衰减的观测差异来源；
  fold 也可以在支撑内部（C16 Lowitz 弧、column 切弧），两者都是焦散亮缘对象，只有前者与
  支撑集耦合；
- **洞**：支撑集的有界补集分量（原「硬暗洞」）；
- **软/硬是观测层属性，不进几何层**：固定 λ 下几何支撑边是理想硬边；观测软化有三个可列
  成因（源盘卷积、谱积分、视觉/MC 分辨率）。三个关注点分开表达：几何硬边（几何层）、λ 间
  移动（色度层-位置色散）、观测软化（量化层）。

**支撑内权重凹陷**归入二维亮域的亮度分析（ρAT/J 剖面）。「暗区」保留为**查询词汇**：对
「这里为什么暗」的输出是一份分解（在支撑哪一侧；若在支撑内给出权重剖面数字），而不是一个
对象类。

与既有机器的衔接：schema3 报告的支撑 δ 轴块是该对象在一维（δ 轴）上的特例（旋转对称测度下
够用）；对象设计把它推广到二维支撑集，恰好覆盖受限族（C10/C16）区域。

支撑集（及一切口径敏感的对象）须带**口径字段**（字面成员 / L1 / L2 / filter 并集）——C12
兄弟链 tint 的口径分歧是先例；口径词汇见 [`raypath-symmetry.md`](raypath-symmetry.md) §1。

### 2.4 owner 产品语义裁定（2026-10-24）

产品就绪盘点轮的三条裁定，属对象空间的表达语义，是后续一切消费实现（含 GUI）的硬前提：

1. **δ 域支撑给出的是总体范围；当前姿态实际点亮的是其中的子集，分层另报。** 不得以
   「这不是二维天空域」为由重做或替换 `support_set`——缺的是在支撑旁边展示姿态产生的像/线/
   亮域，并保留两种语义（总体范围 + 实际点亮子集），不是支撑定义缺陷。
2. **亮线不只一种机制，物理依据分别表达**：22° 晕的 δ 极值边（支撑边重合 fold）；Parry 的
   一维姿态族常规像；切弧/Lowitz 的二维受限族焦散。用户概念可以统一（都是「亮线」），机制
   归属必须分别可检索——这正是 §2.1 五对象 + 统一焦散判据（§3.3）的设计动机。
3. **真实亮弧弧长剖面与局部法向截面列中期**：当前需求是识别/定位/展示亮弧（沿弧长剖面作为
   规范探针的一种已在 §4.2），高级剖面工具不列为第一版前置。

## 3. 分支路由级联

### 3.1 路由的本质（owner 确认 2026-10-17）

路由不是「猜场景像哪个 case」，而是**按固定顺序计算少量结构事实，每个事实关闭或打开一个
分支**。每步产出只有两种：**证书**（机械可查的事实，关闭分支）或**拒答**（记录模式的未知，
带开放串 reason）。猜测不存在于路由层——「报告拒答 ≠ 物理无解」（C17/C18 的 touching /
not_carried）由此从纪律变成结构：拒答是一个记录，不是「无」。

路由变量来自三个相互独立的输入：

1. **光路代数**（展开后的复合算子 M、等效楔角、入/出面）——决定恒等/坍缩；
2. **极限族运动学**（测度 σ→0 极限下，方向映射 q 在族上的 rank）——决定对象是点/线/缘/域；
3. **实际测度 + 有限几何**（ρ、走廊 A、出口 TIR、对称核验）——决定可见性与口径。

**两通道原则**：结构路由用极限族，可见性与口径用实际测度。「近族」≠ 族（Gaussian ±0.3°
拓扑上满支撑：运动学归极限族处理，权重按实际测度积分）。C10 教训：**rank 必须在族上算，
不能在全 SO(3) 算**（全 SO(3) rank 2 而固定 c 轴族 rank 0；位置由结构定、可见性由权重定，
厚度门是两者分工的实例）。族路由的完整语义（集中度三分、冻结阶梯、逐对象存活筛、rank
原语）以 [`gap1-family-routing.md`](gap1-family-routing.md) 为权威，本文不复制。

### 3.2 级联四层

输入 = 有限晶体形状 × L2 类[口径] × 测度 × 源 × λ 栅格。几何在参考 λ 路由一次；边界标签
携带 λ 依赖旗（C06 的 TIR 圆随 λ 移）。

- **T0 代数层**（逐 L2 类，参考 λ）：展开光路 → 复合算子 M、等效楔角、入/出面。证书
  「M=I ∧ 楔角=0」→ 源像，位形分析早停（反射链必须显式核对 M，不能只查楔角）。as-built：
  survey 的恒等证书（M=I 至 1e-12、楔角至 1e-9°，见 `raypath-cli-output.md` §9）。
- **T1 映射结构层**（在极限族 F 上算 rank(q|F)）：rank 0 → 族坍缩点；rank 1 → 一维常规像
  （曲线 + 天空速度；驻点/端点记曲线特征）；rank 2 → 临界集（J=0）→ 焦散亮缘候选 + 正则区
  → 二维亮域；满维 pose 支撑 → q 被淹没，走既有 δ 轴/fiber 机器；像闭包 → 支撑集
  （边界标签/洞）。
- **T2 正权重筛查**（实际测度 + 有限几何：走廊 A / ρ / 出口 TIR / 光学有效域），三分：
  正权重 | 全零（候选保留，标「几何存在、权重零」）| 未知（拒答模式）。
- **T3 量化**（按对象、按预算）：源盘、谱积分、位置/宽度/强度/色度。

**色度层并行、独立触发**：楔角≠0 → 色散检查；近 TIR 份额 / ESS 噪声 / 用户追问 → 权重
检查；不随 T0 早停消失（C15）。

**回退**：任何一步拒答 → 该分支「未知（模式）」+ MC 佐证（不做 oracle 断言）；结构未分类
→ 通用候选发现 + MC。

### 3.3 焦散的统一定义

焦散亮缘 = 「相关投影映射」的临界像；**族维度决定相关映射**——满维 → δ 标量投影的临界
结构（22° min-δ 圈坐支撑边）；二维族 → q|F 本身的临界集（Lowitz fold 在支撑内部）；一维族
→ 无临界集，曲线驻点/端点是天然亮度集中点。C01 与 C16 两类迥异场景共用同一个判据，不是两
套特判。

### 3.4 零权重候选必报不删

「几何存在/权重零」是诊断输出的一部分（C09 光学开弧 A 全零、C10 h0.3）；删掉它就把
「看不见」错误塌缩成「不存在」。T2 三分在证据语言中的展开见 §5.2。

### 3.5 三个已裁定点

1. **路由单元 = (L2 类 × 测度)**。源/谱不参与路由、只进 T3；几何在参考 λ 定一次，λ 依赖
   作为标签旗携带（C06 的 TIR 圆随 λ 移是标签旗+探针线上的检查，不是重路由）。路由结果可
   缓存复用：同光路同测度，换太阳/换谱不重路由。
2. **普查 vs 查询**的分工由三层交互模型承担（§4），两级共存、普查先行。
3. **一维族的驻点/端点** = 曲线特征字段，不升格为独立对象（语料未单独出现该形态；发现了
   再归纳）。

### 3.6 局部拒答不传播为全局无解

两个互补的结构保证，都来自 owner 裁定：

- **分层证据态**（§5.6）：同一对象上，partition 拒答（refused）与正 A 见证（finite）
  **并存不互斥**（C17 touching、C18 not_carried）——拒答住在它自己的声明层上，不覆盖别的层
  的独立依据。
- **拒答作用域**（owner 裁定 2026-10-21，survey as-built）：δ 轴 partition（几何事实）与
  取向阶梯（测度事实）是两条相互独立的腿；partition 拒答的作用域收窄到它自己的 level-0
  支撑卡，阶梯照常枚举，chromatic/tint 腿跟随对象；文档级回滚定律 = 有任何 finite 结构对象
  ⇒ 文档 finite，全部结构腿无 finite 输出才 refused。五条语义与机制细节见
  [`gap1-family-routing.md`](gap1-family-routing.md) §3。

## 4. 三层交互映射（owner 提出模型，2026-10-17）

| 层 | 内容 | 对应 |
|---|---|---|
| L0 既有 | 光路列表（能量份额、ROI、Exclude） | 已交付的 GUI Analysis 面板 + `Lumice analyze`，不动 |
| L1 普查（点选光路） | T0–T2 全跑 + 逐对象规范探针（预算内 T3） | 对象卡片 + 证据态（`raypath survey`，schema4） |
| L2 查询（点选天空点/画线） | 探针库在用户选定位置 + 该点 fiber 因子分解 | ρ/A/T/K 贡献曲线、剖面带峰标注、暗区分解（`raypath point` / `raypath probe`） |

### 4.1 规范探针是共享库，两级触发

普查的量化不是全场（那是把渲染重做一遍），而是**逐对象固有方向**：支撑边/焦散缘 → 边缘
法向剖面（C01 锐边 vs 峰、C09 红边宽度）；曲线 → 沿弧长剖面；环形/随机族 → 对太阳径向
（δ 轴天然就是）；二维亮域 → 峰域位置 + 少数边际剖面。用户查询画的线（径向/切向等）是
**同一批探针**，区别只在触发权：普查自动跑对象固有的子集，查询让用户在选定位置调全库。
一份实现、两级触发；探针类型定义属能力层（本篇 §7 的命令面），GUI 摆放属交互设计（进行中，
见 §9）。

### 4.2 两条边界

- **普查成本不含 MC 佐证**。MC 是用户手里已有的渲染，作佐证用；普查重活 = 结构 + 筛查 +
  规范探针。as-built 演化：gap③ 在 survey 上加了 **opt-in** 的 MC ESS 佐证腿
  （`--mc-ess <draws>`，不传则文档中不出现该键；固定种子可复放）——边界语义不变：默认
  普查仍是纯结构+解析量化，MC 佐证永远显式请求、独立于结构主证（§5.3）。单光路佐证的
  band-sum/MC 分层与时机见 §5.4。
- **survey 是查询的索引**。点击一个天空点，裸的只是方向；有普查后变成「在支撑集 X 内部、
  距 TIR 边 Y 0.3°」——L2 因子分解才有结构可依托，答案按对象组织（点在边附近自动带法向
  剖面，落在 TIR 渐变带自动带份额分解）。没有普查的查询是盲查。无状态 CLI 下这条边界的
  物理形态就是 `--warm` 索引契约（§7.2）。

### 4.3 色度层落位与 L2 语义边界

整体色/边缘色在普查量化（边缘跨 λ 堆叠、对象整体 tint 是对象固有属性）；条带色普查只出
旗标（TIR 份额过渡存在），剖面细节留 L2——C18 的 ESS/噪声诊断住 L2。

「沿 fiber 展示具名因素与总贡献」的产品愿望落在 L2 点查询；「没人组织计算去解释」的缺口落
在 L1。两者是同一管线的两个刻度：L1 决定算什么（结构路由），L2 展示为什么（因子分解）。
L2 输出的语义边界原样继承自份额类输出的既有纪律：不报可加百分比、保留真实量纲、声明 ε 与
分量完备性。

**延后注记**（属交互/产品形态）：点击天空点而未先选光路的跨光路归因（「这处亮是谁」，
依赖全部已列光路的普查索引）；多光路同处叠加的复合特征。

## 5. 证据与未知表达

### 5.1 证据状态是声明的修饰符（owner 确认 2026-10-17，两轮）

每个输出（对象卡片的每个字段、每条查询回答）= **内容 + 证据状态**。证据状态不是声明的
类型，是每个声明各自携带的修饰符——整体打分既会把强依据拉低，也会把弱依据洗白（C01：同一
对象上边位闭式、峰位剖面计算，两种证据强度不同）。

### 5.2 主状态四值（封闭枚举；命名暂定、语义是交付物）

| 状态 | 含义 | 语料例 |
|---|---|---|
| `certified` | 闭式/代数/穷举证明，方法具名 | M=I∧零楔角（C14）、partition 完备证书 |
| `finite` | 有限计算，必须携带覆盖声明（N、分辨率、域、种子） | tint 谱积分比值（C15） |
| `refused` | 拒答，模式为开放串（touching / not_carried / degenerate / budget / …） | C17 touching、C18 not_carried、C12 预算耗尽 |
| `unevaluated` | 未算，带原因（问题未问 / 超范围 / 预算） | T1 臂 tint 的预算让位 |

- 拒答模式用开放串，复用 analytic API 的既有先例（status 封闭 / reason 开放）：成因不可
  预枚举，判定必须可 switch。
- schema 上状态**必填、带默认值**（默认 = `finite` + 本次运行覆盖参数）：状态缺席永远不读作
  「确凿」。

**不对称原理**：见证即存在，零需穷举。一个正见证即证明存在（量级另算）；`finite`-零是弱零
（可能漏采），`certified`-零才是强零；`refused` 永不显示为零/无（C17/C18 的结构化）。
「弱尾 ≠ 严格零」（C09 125°）与「MC 未见 ≠ 零支持」同族。T2 三分在证据语言中展开：
正权重（finite 见证或更强）/ 零（注明 finite 或 certified）/ 未知（refused+模式）。

### 5.3 MC 注记：正交、四值

MC 不与主状态抢枚举位（「证书 + 渲染一致」常见共存）：

- `agrees`：渲染区域有信号；
- `silent`：无信号——**不是矛盾**，可能亚阈值/噪声下（几何上 computed 不保证 visibly
  bright）；
- `conflicts`：超容差不一致——红旗，指向 bug 或口径错，本身不是物理结论；
- `not-run`：异步未跑/按需未触发。

### 5.4 band-sum 是 L1 量化的引擎，不是佐证

- L1 同步跑**参考 λ 单光路全天图**；规范探针 = 该图的切片；色度 λ 栅格只在探针线上，不跑
  多波长地图（C06：TIR 圆随 λ 移是探针线上的检查）。
- 确定性改善 `silent` 语义：无噪声下「低于阈值」= 模型内真小（C09 弱尾类判断从目视变成
  可量）。
- band-sum 是探针/对象量化的 `finite` 依据本体；其完备性 = **种子覆盖**（fiber 续走找不到
  的分量会缺，C17/C18 正是 partition 拒答但 fiber 有正 A）⇒ 永远 `finite` + 覆盖声明，不因
  确定性升格 `certified`。
- 结构对象 vs band-sum 地图的比对 = **模型内自检**（抓算法不一致），与 MC 注记分列。

**前向链分层**（owner 三点裁定，2026-10-17）：

| 层 | 来源 | 时机 | 佐证价值 |
|---|---|---|---|
| 能量级标量 | 分析运行 per-chain 能量（L0 已有） vs band-sum 全图积分 | v1 进（口径对齐接线：mono-λ 或谱积分口径声明） | 独立前向链标量对照 |
| 场景级 | 用户已有的混合渲染 | 用户眼睛（**不做弱注记**，避免弱语义污染输出） | —— |
| 空间单光路 | 专用低分辨率单 λ MC | 按需/异步，不进 L1 同步 | 空间分辨独立佐证、`conflicts` 红旗主力 |

独立链记账：band-sum 与结构路由共享前向光学模型（不同算法、同一模型）——抓算法 bug 不抓
模型 bug；MC 是不共享失败模式的前向链。经济学：单光路 MC 是拒绝采样（有效样本 N×p(该路)，
p 对多界面长链最小）；低分辨率/单 λ 省像素和谱、省不了 p。MC 天然「全路径求和」，band-sum
天然单路径——工具形状决定各自所在层。

### 5.5 分层声明与传播

声明分四层各自带状态：**结构 / 权重 / 可见性 / 完备性**（完备性 = 关于对象清单本身的声明；
schema3 completeness certificate 已有此形态）。C17 是分层必要性的直接证据：同一对象上
partition=refused(touching) 与 declared-source A>0=finite 见证**并存**，不分层就只能互相
覆盖。

传播规则：**派生声明继承上游最弱状态，除非有独立依据**（闭式位置不因上游 partition 拒答而
降级——它有独立代数依据；该逃生口边界 owner 已认）。

## 8. 验证方法论

### 8.1 覆盖驱动，不是条数驱动（owner 确认 2026-10-18）

### 8.2 断言四类与两档容差

每 case 一张断言表，四类断言：对象存在/不存在（**负断言同权**：早停负断言、零权重候选必在
列表）；位置/数量 + 容差；证据态断言（refused 模式串、certified 方法名、finite 覆盖声明在
场）；色度数字（B/R + 口径声明）。

容差两档：**闭式锚**（如 C10 的 δ=108.937304°、C09 的 ~149.0849° 边、C01 的 22° 内缘）跨
版本稳定紧容差；**采样数字**（tint 比、份额）= 特定 binary + 种子上的断言，带口径重跑或
独立重算，不直接当硬断言。

**oracle 纪律**：语料人工终态 = oracle；验收 ≠ 产品 PASS。对不上时三分归因（装配错 / 真缺
口显形 / 语料口径过期）——红态是信息。语料 config 正式 fixture 化时按 cases 文档的
只增不复用规则走 `doc/cases/` 锚。
